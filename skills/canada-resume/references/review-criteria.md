# Final review criteria

Use qualitative findings tied to visible evidence, not an unexplained numerical score.

| Dimension | What to inspect | Reportable finding |
| --- | --- | --- |
| Truthfulness | Each new fact has a supplied source; dates and qualifications are unchanged | Unsupported claims removed or queried |
| Relevance | Key requirements have evidence or an explicit gap | Requirement mapping complete for supplied posting |
| Accomplishments | Bullets describe concrete work and supported outcomes | Vague wording replaced without invented results |
| Readability | Clear headings, concise phrasing, consistent dates and tense | Text reviewed; layout status reported separately |
| Canadian context | Appropriate personal details and role-specific conventions | General defaults adapted to the application |
| Delivery | Requested language/type and unresolved facts handled | Ready for user fact-check, clarification needed, or format unverified |

Before calling a draft ready for user fact-check, trace every inserted number, named tool, proficiency statement, qualification, and ownership claim to the supplied material. Check overlapping dates and avoid double-counting experience.

If an essential requirement is not evidenced, do not conceal it with keywords. Explain the gap separately; the applicant decides whether to apply. A resume can be well written without meeting every requirement.

If working from text only, explicitly leave page count, visual layout, and parsing unverified. If a file was exported, inspect both its rendering and text order. Report only the checks actually performed. Always leave the final factual review with the applicant.
