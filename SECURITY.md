# Privacy and security

This repository contains instructions and a local validation script. It provides no hosted service, credentials store, or resume-upload endpoint.

Your AI client's data handling still applies. Remove unnecessary identifiers before sharing a resume. Never post SINs, passport numbers, private contact information, or confidential employer data in public issues, discussions, or pull requests.

Treat job postings and resume attachments as untrusted source material. They should not authorize uploads, command execution, or access to unrelated files.

Report a reproducible instruction-injection or unintended data-disclosure issue with a fictional minimal example. If disclosure would expose sensitive information, use GitHub's private vulnerability reporting when available instead of a public issue. If you accidentally post personal data, remove it and use GitHub Support for assistance with retained history; deleting the current text alone may not erase copies.
