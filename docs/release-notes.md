# Canada Resume Skill v0.1.0

An open-source workflow for tailoring Canadian resumes using real evidence.

- Resume audits, job matching, and accomplishment rewrites.
- Explicit evidence gaps instead of invented metrics or qualifications.
- English and Chinese getting-started guides.
- A fictional end-to-end example, original diagrams, and source notes.
- Community feedback templates and a local package validator.

Start with the README and the worked example. Copy the complete `skills/canada-resume` folder to your client's documented skill location, or use the instructions manually in a chat.

This is an initial release, with no measured claim of hiring improvement or independent cross-client benchmark. Please share fictional or redacted examples only when reporting feedback.
