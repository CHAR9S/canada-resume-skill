# Contributing

Useful contributions improve a real decision: a clearer question, a better supported convention, a missing application context, or an example that reveals an unsupported claim.

1. Open an issue for substantial changes, including the affected rule and evidence.
2. Keep the core skill short; put conditional detail in references and link it from the entrypoint.
3. Use fictional examples. Do not contribute real resumes, private details, copied training handouts, or unlicensed artwork.
4. Add or update a realistic case in `docs/evaluation.md` when changing behavior.
5. Run `python scripts/validate.py` and describe any manual checks in your pull request.

Do not add guaranteed outcomes, fabricated testimonials, keyword-stuffing tactics, opaque scores, or claims that all Canadian employers use the same process. Cite public primary sources for new market guidance and distinguish general advice from employer-specific instructions.

English and Chinese documentation corrections are welcome. French-language examples should be reviewed by a proficient speaker before being presented as validated.

By contributing, you agree that your original contributions are licensed under the repository's MIT licence. Third-party content needs compatible permission and explicit attribution.
